# Tommy's NixOS Configuration

A personal NixOS configuration built around **Hyprland + Noctalia**, managed with Nix flakes and Git.

This configuration is designed to provide a reproducible desktop setup while keeping machine-specific hardware configuration local to each system.

## What This Includes

* **NixOS 26.05**
* **Hyprland**
* **Noctalia**
* **Kitty**
* **Yazi**
* **Zen Browser**
* **Fish**
* **Steam**
* **Discord**
* **Spotify**
* **Nautilus**
* Custom wallpapers
* Custom Hyprland configuration
* Noctalia community templates and palettes

## Hardware Configuration

`hardware-configuration.nix` is generated by NixOS for each machine and is **not tracked by Git**.

It contains hardware-specific information such as filesystems, UUIDs, disk configuration, and kernel modules.

The configuration imports it from:

```text
/etc/nixos/hardware-configuration.nix
```

Because this file is outside the flake source, rebuilds use:

```bash
sudo nixos-rebuild switch --impure --flake /etc/nixos#nixos
```

## Installation

### 1. Generate the Hardware Configuration

NixOS normally generates the hardware configuration during installation. If it is not present, run:

```bash
sudo nixos-generate-config --root /
```

Make sure the following file exists:

```text
/etc/nixos/hardware-configuration.nix
```

### 2. Get Git

If Git is not available:

```bash
nix-shell -p git
```

Verify the installation:

```bash
git --version
```

### 3. Clone the Repository

Clone the repository somewhere outside `/etc/nixos`:

```bash
git clone https://github.com/quicktommy/nixos-config.git ~/nixos-config
```

### 4. Copy the Configuration

Copy the repository contents into `/etc/nixos`:

```bash
sudo cp -a ~/nixos-config/. /etc/nixos/
```

This preserves the machine's existing `hardware-configuration.nix`.

### 5. Configure Your Username

Before rebuilding, open:

```text
/etc/nixos/configuration.nix
```

At the top of the file, find:

```nix
let
  userName = "tommy";
```

Change `"tommy"` to the username you created during the NixOS installation.

For example:

```nix
let
  userName = "yourusername";
```

**This is the only username value that needs to be changed.**

The configuration uses this variable to create and configure the user and to deploy the home configuration to the correct `/home/<username>` directory.

### 6. Rebuild

Apply the configuration:

```bash
sudo nixos-rebuild switch --impure --flake /etc/nixos#nixos
```

The rebuild installs the configured software and deploys the files from `home/` into the appropriate locations in the configured user's home directory.

### 7. Reboot

Reboot into the newly configured system:

```bash
sudo reboot
```

## Starting Hyprland

This configuration currently uses a **TTY login** rather than a graphical login manager.

After booting:

1. Log in with your user account.
2. Start Hyprland:

```bash
start-hyprland
```

Hyprland and Noctalia will then start using the deployed configuration.

## Configure the Monitors

Monitor configuration should be performed **after starting Hyprland**, since the available monitor outputs can be identified from the running Hyprland session.

First, check the connected monitors:

```bash
hyprctl monitors
```

The repository contains the monitor configuration in:

```text
/etc/nixos/home/hypr/config/variables.lua
/etc/nixos/home/hypr/config/monitors.lua
```

**Edit these files in the repository, not the deployed copies under `~/.config/hypr/`.**

Edit `variables.lua` to set `MONITOR1`, `MONITOR2`, etc. to the output names shown by `hyprctl monitors`.

Then edit `monitors.lua` to configure the desired resolution, refresh rate, position, and scale.

The configuration under `home/` is the source that gets deployed to the user's home directory during a rebuild. Therefore, monitor changes made only to `~/.config/hypr/` may be overwritten by the next rebuild.

After making the monitor changes in `/etc/nixos/home/hypr/config/`, rebuild the system:

```bash
sudo nixos-rebuild switch --impure --flake /etc/nixos#nixos
```

## Applying Changes

After modifying the NixOS configuration or files under `home/`, rebuild with:

```bash
sudo nixos-rebuild switch --impure --flake /etc/nixos#nixos
```

Changes to files under `home/` are automatically deployed during the rebuild.

## Configuration Philosophy

This repository is a **personal NixOS configuration**, not a general-purpose NixOS distribution.

It focuses on:

* Reproducibility
* Declarative system configuration
* Version control
* Personal desktop customization
* Keeping machine-specific hardware data out of Git
* Easy recovery after reinstalling NixOS

**My setup, but declarative.**
